# 产品需求文档（PRD）：静态个人博客网站

## 1. 项目概述

构建一个无需后端的纯静态个人博客网站，文章内容通过JSON格式存储和渲染。用户可以浏览文章、按标签过滤，文章详情以HTML格式渲染为内嵌页面。

## 2. 目标用户

- 个人博主/开发者
- 希望拥有轻量级、易维护博客的用户

## 3. 功能需求

### 3.1 核心功能

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 文章列表展示 | 主页展示所有文章卡片，包含标题、摘要、标签 | P0 |
| 文章详情查看 | 点击文章后，在页面内嵌入渲染HTML内容 | P0 |
| 标签过滤 | 点击标签可过滤显示对应文章 | P0 |
| JSON数据管理 | 所有文章内容存储在JSON文件中 | P0 |

### 3.2 非功能性需求

| 需求 | 描述 |
|------|------|
| 纯静态 | 无需任何后端服务，可直接部署到静态托管服务 |
| 响应式设计 | 适配桌面、平板、手机等多种设备 |
| 加载性能 | 首屏加载快速，JSON数据按需加载 |

## 4. 数据结构

### 4.1 文章JSON格式

```json
{
  "id": "unique-id",
  "title": "文章标题",
  "summary": "文章摘要（可选）",
  "content": "<p>HTML格式的正文内容</p>",
  "tags": ["tag1", "tag2"],
  "date": "2024-01-01",
  "cover": "封面图URL（可选）"
}
```

### 4.2 文章索引格式

```json
{
  "articles": [
    {
      "id": "article-1",
      "title": "第一篇文章",
      "summary": "文章简介",
      "tags": ["技术", "前端"],
      "date": "2024-01-15",
      "cover": ""
    }
  ]
}
```

### 4.3 文章内容文件

每篇文章的完整HTML内容存放在独立的JSON文件中：`data/articles/{id}.json`

## 5. 页面结构

### 5.1 主页

- 顶部导航栏（站点名称/Logo）
- 文章列表区域
- 标签云/过滤器区域

### 5.2 文章详情页

- 点击文章后，在主页内展开或滑入显示
- 面包屑导航或返回按钮
- 完整HTML内容渲染区域

## 6. 技术约束

- 纯前端实现：HTML + CSS + JavaScript
- 无框架依赖或使用轻量级框架
- JSON数据作为数据源
- 可部署到 GitHub Pages、Netlify、Vercel 等静态托管平台
